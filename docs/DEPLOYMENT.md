# DEPLOYMENT & DEVOPS PIPELINE (v5.0)

## Infrastructure Stack
- **Hosting**: Vercel (Edge Network & Serverless Functions).
- **Database**: Managed PostgreSQL on Supabase / Neon with Prisma migrations.
- **Media CDN**: Cloudinary for high-res food images and 9:16 vertical video reels.
- **CI/CD**: GitHub Actions automated lint, build verification, and deployment.
